# CDBox 标注浮窗动画设计文档 v1.0

## 1. 功能目标

为 CDBox 标注对象编辑浮窗增加现代化打开/关闭动画，提高对象编辑体验。

当前目标：

1. 浮窗打开时：
   - 从标注绑定点位置展开；
   - 产生“该编辑器属于该对象”的空间关联感。
2. 浮窗关闭时：
   - 反向收回至绑定点。
3. 浮窗最终显示位置：
   - **不自动避让**
   - **不根据标注文字位置计算**
   - **不跟随对象移动**
   - 使用用户上一次关闭时的位置。

本版本仅验证动画交互效果。

------

# 2. 交互逻辑

## 2.1 打开流程

触发：

- 双击标注对象；
- 或其他已有编辑入口。

流程：

```
用户双击标注

↓

获取标注绑定点屏幕坐标

↓

读取浮窗上次关闭位置

↓

浮窗初始化于绑定点位置

↓

执行展开动画

↓

移动至记忆位置

↓

进入正常编辑状态
```

------

示意：

```
CAD空间


      管线
─────────────


        ●
        ↑
     绑定点


        ↓展开


             ┌──────────┐
             │ 标注编辑器 │
             └──────────┘
```

------

# 3. 关闭流程

流程：

```
用户关闭浮窗

↓

记录当前位置

↓

执行收回动画

↓

动画结束隐藏窗口
```

示意：

```
┌────────────┐
│ 标注编辑器 │
└────────────┘

        ↓

        ●

绑定点
```

------

# 4. 浮窗位置管理

## 4.1 位置来源

取消：

- 自动避让；
- 标注位置分析；
- 屏幕边缘判断；
- CAD空间位置计算。

采用：

```
LastWindowPosition
```

保存：

```
double LastLeft;
double LastTop;
```

------

## 4.2 生命周期

首次打开：

无历史位置：

```
绑定点 + 默认偏移
```

例如：

```
X + 20px
Y + 20px
```

后续打开：

```
使用上一次关闭位置
```

------

# 5. 动画设计

## 5.1 动画技术方案

使用 WPF 原生动画：

核心：

- ScaleTransform
- TranslateTransform
- Opacity

不修改 Width / Height。

原因：

- 避免布局刷新；
- 动画更加流畅；
- 适合浮窗。

------

# 6. 打开动画

初始状态：

位置：

```
绑定点
```

属性：

```
ScaleX = 0.85
ScaleY = 0.85

Opacity = 0

Translate = 绑定点 → 目标位置
```

结束：

```
ScaleX = 1
ScaleY = 1

Opacity = 1

Translate = 0
```

参数：

| 属性 | 值        |
| ---- | --------- |
| 时间 | 200ms     |
| 缓动 | CubicEase |
| 方向 | EaseOut   |

效果：

```
绑定点

  ↓

快速展开

  ↓

停留编辑位置
```

------

# 7. 关闭动画

初始：

```
Scale = 1

Opacity = 1
```

结束：

```
Scale = 0.85

Opacity = 0

位置移动到绑定点
```

参数：

| 属性 | 值        |
| ---- | --------- |
| 时间 | 150ms     |
| 缓动 | CubicEase |
| 方向 | EaseIn    |

# 8. 动画控制结构

建议新增：

```
AnnotationEditor
│
├── AnnotationEditorWindow
│
├── PopupAnimationController
│
└── PopupPositionManager
```

------

## PopupAnimationController

职责：

只负责动画。

不处理：

- CAD对象；
- 标注数据；
- 窗口位置保存。

接口：

```
public class PopupAnimationController
{

    public void Open(
        Window window,
        Point origin,
        Point target
    )


    public void Close(
        Window window,
        Point origin
    )

}
```

# 9. 绑定点坐标转换

CAD中的绑定点：

通常为：

```
World Coordinate
```

需要转换：

```
CAD坐标

↓

屏幕坐标

↓

WPF窗口坐标
```

流程：

```
Point bindingPoint =
    Editor.PointToScreen(worldPoint);
```

然后用于动画 Origin。

# 12. 设计原则

CDBox 标注浮窗不是传统对话框。

它属于：

```
CAD对象
   |
   |
绑定关系
   |
   |
对象编辑器
```

因此动画必须体现：

> 编辑器从对象中产生，而不是随机弹出。

本版本先验证“绑定点展开/收回”的交互感受，再决定是否扩展更复杂动画逻辑。
