# CDBox 组件化安装与业务模块分离执行文档

## 1. 最终目标

CDBox 安装单元固定分为四类：

1. 基础组件 `base`：必须安装，负责 AutoCAD 加载入口、模块宿主、公共契约、运行环境、更新能力和组件状态管理；
2. 公共业务 `common`：可选，承载不属于单一专业的测绘及通用业务功能；
3. 污水业务 `wastewater`：可选，承载污水管线工作台、检查、同步、计算、标注及成果输出；
4. 不动产业务 `realestate`：可选，承载宗地调查、界址调查、建筑边长注记及成果导出。

最终安装器应成为统一的本机 CDBox 管理工具，支持：

- 首次安装；
- 完整卸载；
- 为一个或多个已安装 AutoCAD 版本增加业务组件；
- 移除业务组件；
- 修复基础组件和运行环境；
- 更新时保留每个 AutoCAD 安装目标已有的组件组合。

## 2. 不可破坏的依赖规则

- `base` 不依赖任何业务组件；
- `common`、`wastewater`、`realestate` 只允许依赖基础组件和公共契约；
- 污水业务与不动产业务不得互相引用；
- 公共业务不得反向引用污水业务或不动产业务；
- AutoCAD 命令入口保留在基础组件中，通过固定模块文件和固定类型转发；
- 未安装或加载失败的可选组件不得影响基础组件及其他业务组件启动。

## 3. 当前阶段状态

| 组件 | 程序集边界 | 安装器状态 | 说明 |
| --- | --- | --- | --- |
| 基础组件 | `CDBox.dll`、`CDBox.Shared.dll` | 强制安装 | 包含模块宿主、组件状态及必装图层管理器；分类模型和识别引擎位于 Shared |
| 公共业务 | `CDBox.Common.dll` | 可选安装 | 简码识别、图框工具和 Excel 转 CAD 已物理迁入，主程序集仅保留命令转发 |
| 污水业务 | `CDBox.Wastewater.dll` | 可选安装 | 0.8.0 已物理迁移污水标注、纵断面、断面成果生成、CAD 交互及独立页面控制器 |
| 不动产业务 | `CDBox.RealEstate.dll` | 可选安装 | 已具备独立程序集和固定加载边界 |

安装器内部 `Contents/components.json` 是组件文件归属和依赖清单；安装完成后，安装器在 `Contents/components.installed.json` 保存当前 AutoCAD 安装目标的组件选择。网络更新启动安装器时会把当前组合预选到安装器界面，用户仍可在应用前调整。

### 网络更新适配完成情况

- CDBox设置显示当前组件组合；网络更新仅下载经 SHA256 校验的版本化 EXE 安装器，不再下载 ZIP；
- `update.json` 使用 `installer` 节点描述文件名、大小、SHA256 和下载源，不再生成 `package` 节点；
- 安装器是唯一生命周期入口，统一承担首次安装、更新、增加模块、移除模块和插件卸载；插件内部不再提供本地 DLL 安装或本地更新入口；
- 更新时先注销加载注册并完整移除当前 `CDBox.bundle`，再按安装器中最终选择的组件安装新版本；安装失败时恢复旧 bundle 和加载注册；
- 组件状态缺失或损坏时根据现有程序集和业务模板反推当前组合；基础组件和组件依赖始终自动补齐；
- 发布只上传 `CDBox安装器.<版本>.exe` 和 `update.json`，不再发行外部压缩包，也不再包含 `CDBoxUpdater.exe`、`pending-update.json` 或 `last-update-result.json` 链路；
- 用户 AppData 配置不参与安装目录替换和卸载，完整卸载插件时仍保留用户设置与业务缓存。

### 阶段 B 完成情况

- 简码识别解析、设置持久化、CAD 绘制和独立设置页已迁入 `CDBox.Common.dll`；
- `CDSHORTCODE`、`CDJMSB`、`CDSHORTCODESET`、`CDJMSZ` 由基础组件保留兼容命令名，并通过固定模块边界转发；
- 主程序集不再编译简码识别业务实现；
- 因污水管线的图层分类是业务运行前提，图层管理器已调整为必装基础能力：规则存储、预设、CAD 批量操作、属性识别表和独立页面由 `CDBox.dll` 承载；
- `TCP_LAYERS`、`CDLAYER`、`TCGL`、`GDTC` 直接进入基础图层管理器，不再依赖 `CDBox.Common.dll`；
- 图层元数据值对象、识别规则模型、规则引擎和颜色值对象保留在 `CDBox.Shared.dll`，供基础组件与各业务模块共享稳定契约；
- 图框模型、设置、预览、裁图区域与布框 CAD 服务已迁入 `CDBox.Common.dll`，`TCFRAMEADD`、`TCFRAMECUT`、`TCFRAMELAYOUT`、`TCFRAMEPLACE`和 `TCFRAMESET` 由基础组件动态转发；
- Excel 选区桥接、表格读取、CAD 生成服务和独立页面已迁入 `CDBox.Common.dll`，`CDEXCEL`与 `GU_XL` 由基础组件动态转发；
- 基础组件对公共业务程序集无静态引用；未安装或加载失败时仅对相应命令给出提示，不影响基础组件和其他业务启动；
- 安装器已开放公共业务复选框，默认选中但可取消；取消后发布包裁剪 `CDBox.Common.dll` 及调试符号文件；
- `WastewaterResultTable` 的数据模型、排序格式、选取预览和 CAD 绘制已迁入 `CDBox.Wastewater.dll`；`WSGCGB`、`CDWELLTABLE` 仅在基础组件保留 AutoCAD 命令壳并动态转发；
- 基础组件通过纯数据接口向成果表提供旧图纸井属性，通过基础图层分类接口回写“污水管成果表”图层归属，`CDBox.Wastewater.dll` 不反向引用 `CDBox.dll`。
- 污水工作台页面、分组导航及命令路由已迁入 `CDBox.Wastewater.dll`，基础组件只提供通用页面宿主和 CAD 命令执行接口；业务页面执行图纸交互时会自动隐藏，完成后恢复；
- 工程量属性值对象、默认表和值计算结果等稳定合同已下沉 `CDBox.Shared.dll`，供基础 CAD 适配层与污水业务共同使用；
- 属性联动规则、默认值持久化及工程量数学计算核心已迁入 `CDBox.Wastewater.dll`，基础组件通过 `IQuantityAttributeEngine` 注册表调用，不静态引用污水程序集；
- 属性编辑器 HTML/脚本、JSON 路由、草稿联动控制器和独立页面已迁入 `CDBox.Wastewater.dll`；基础组件旧页面只保留打开模块页面的兼容壳；
- 工程量属性 Xrecord 的读取、写入、删除、命名对象字典备份和跨图纸克隆修复已迁入 `CDBox.Wastewater.dll`，保持原键值格式及旧图纸兼容；
- 基础组件通过 `IQuantityAttributeEditorCadService` 提供图纸、对象句柄、选择和锁定适配，通过 `IQuantityAttributeCadStore` 注册表调用污水存储实现；未安装污水模块时读取安全返回无属性，不影响基础组件启动；
- 工程量看板的数据模型、汇总/质量检查、快照缓存、参考表和计算过程导出、独立页面及路由控制器已迁入 `CDBox.Wastewater.dll`；旧综合 Studio 只保留打开模块页面的占位壳；
- 工程量统计区域的创建、绑定、重命名、删除、范围判定和选择记忆已迁入污水程序集；基础检查、同步和旧属性流程通过 `IQuantityDashboardScopeService` 不透明 CAD 适配边界复用区域范围；
- 正式工程量表的选择流程、计算逻辑、模板填充和 Excel 输出已迁入污水程序集，`GCL` 仅保留基础命令转发；`工程量计算表模板.xls` 已列入污水组件文件归属；
- 管径、井规格、材质、支管类型、沟槽宽度、结构层等智能补全规则已迁入污水属性计算引擎；基础组件只采集 CAD 图层元数据并通过 `IQuantityAttributeEngine` 调用；
- 图纸检查快照模型和同步任务模型已下沉 `CDBox.Shared.dll`，检查规则、分组、状态机、忽略记录持久化及同步任务合并/冲突/历史状态已迁入 `CDBox.Wastewater.dll`；
- 基础组件通过 `IWastewaterInspectionService` 与 `IWastewaterSyncService` 注册表调用模块，只保留 CAD 分批扫描、事件接入、命令执行和悬浮球呈现；未安装污水模块时返回空状态且不启动污水检查、同步；
- 当前保留在基础组件内的 `QuantityPipeAttributeService` 只承担 AutoCAD 实体识别、节点连接、图层分类和其他尚未迁移业务的兼容编排，不再包含可执行的 Xrecord 持久化或智能默认规则实现。
- 污水管长标注与节点标注的配置模型已下沉 `CDBox.Shared.dll`，文字组合、设置持久化、CAD 对象选择、引线预览、对象绑定、成果实体生成和文档监听均迁入 `CDBox.Wastewater.dll`；基础组件只通过 `IWastewaterCadInteractionService` 注册表转发刷新和双击编辑请求；
- 纵断面管网拓扑、起终点寻路、节点高程、坡度计算、设置持久化、图纸采集、最终 CAD 实体绘制和独立设置页控制器均已迁入 `CDBox.Wastewater.dll`；
- 批量断面结构层转换、同结构合并、连续井段标题合并、CAD 对象读取、成果落图及独立页面控制器均已迁入 `CDBox.Wastewater.dll`；
- 三组功能分别通过 `IWastewaterAnnotationEngine`、`IWastewaterLongitudinalProfileEngine` 和 `IWastewaterSectionDrawingEngine` 注册表接入，模块关闭后全部注销，不形成 `CDBox.dll` 对 `CDBox.Wastewater.dll` 的静态引用。

### 阶段 B：公共业务物理迁移

- 已完成。公共业务 0.5.0 包含简码识别、图框工具及 Excel 转 CAD；图层管理器因污水业务硬依赖已归入基础组件；
- 已建立通用模块页面的 CAD 交互回调，交互期间独立页面自动隐藏，完成后恢复；
- 已覆盖程序集归属、单向依赖、动态命令、组件裁剪和污水成果表隔离回归。

### 阶段 C：污水业务物理迁移

- 已完成：污水业务 0.8.0 已物理承载污水工作台、属性编辑器、工程量属性业务核心、CAD 属性存储、工程量看板、区域范围、正式工程量表、管线智能计算、图纸检查、同步任务、污水管成果表，以及污水标注、纵断面和断面功能的业务计算、CAD 图形交互、成果实体生成与独立页面控制器；安装器已开放污水业务自由选择；
- 已建立页面宿主、CAD 命令执行、旧属性读取和基础图层分类等单向服务契约，后续污水功能沿用相同边界迁移；
- 已删除基础工作台中的污水功能兼容列表、旧断面兼容命令和模块缺失时的旧工作台回退；未选择污水业务时只保留基础/公共功能，污水命令统一提示模块未安装或加载失败；
- 删除主程序集内的污水兼容实现；
- 验证仅安装基础组件、基础加污水、基础加不动产等组合；
- 完成后开放污水业务复选框。

### 阶段 D：统一组件管理工具（已完成）

- 检测每个 AutoCAD 版本的已安装状态和组件组合；
- 同一安装器完成安装、更新、增加组件、移除组件和完整卸载；
- 每次应用先完整替换旧版本，再写入最终组件状态；失败时恢复旧版本；
- 移除最后一个业务组件时保留基础组件，只有点击完整卸载才删除基础组件和加载注册；
- 网络更新与发行已统一为安装器单文件，不再保留 ZIP 更新和插件内本地安装组件。

## 5. 验收组合

至少覆盖以下安装组合并分别验证 CAD 2016 与 CAD 2023；其他检测到的 AutoCAD 版本使用同一套产物：

- 仅基础组件；
- 基础组件 + 公共业务；
- 基础组件 + 污水业务；
- 基础组件 + 不动产业务；
- 基础组件 + 任意两个业务组件；
- 全部组件；
- 已安装组合更新后保持不变；
- 增加和移除组件失败时可自动回滚。
