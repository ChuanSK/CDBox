# CDBox 组件管理器技术设计

## 架构

- `InstallerPlanEvaluator`：纯状态计算层，比较安装目标、已安装版本、已安装组件与期望组件，生成动态主操作、组件状态和待应用更改。
- `InstallerPresentationCatalog`：保存组件说明和只读功能分组；与物理组件清单分离。
- `InstallerForm`：仅负责 WinForms 呈现、用户交互和调用现有安装服务。
- `BundleInstallService`：继续承担原子替换、注册、卸载；增加只读安装快照和安装目录能力。
- `CDBoxComponentDefinition`：增加可选兼容元数据，为以后按 AutoCAD 年份和核心版本限制组件预留。

## 页面结构

顶部摘要 → 安装目标卡片 → 安装方案分段控件 → 左侧组件树 / 右侧详情 → 环境和 CAD 状态 / 折叠日志 → 固定操作栏。

组件树使用自绘扁平控件：只有物理组件行具备选择框，功能叶节点仅为缩进文字。详情面板展示说明、包含功能、版本、安装状态和兼容信息。

## 状态规则

- 未安装目标：安装。
- 已安装但产品版本不同：更新。
- 版本相同但组件组合不同：应用更改。
- 版本和组件均一致：已是最新配置并禁用主按钮。
- 用户明确选择修复：修复安装。
- AutoCAD 运行中或无目标：禁用破坏性操作。

## 验证

- 为方案选择、动态操作、待应用更改、组件状态和兼容判断增加纯逻辑测试。
- 构建安装器并运行载荷校验。
- 回归现有安装、完整替换、模块增减与卸载测试。
