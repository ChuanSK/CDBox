# CDBox 组件管理器重构需求

## 范围

将现有传统 WinForms 安装页重构为统一的 CDBox 安装与组件管理器，继续复用现有完整替换安装、模块裁剪、前置组件自动安装和卸载能力。

## 用户故事与验收条件

1. 作为普通用户，我只需要选择 AutoCAD 目标和真正可安装的业务模块。
   - 当安装器显示组件时，系统应只为基础、公共、污水和不动产四个物理组件提供选择状态。
   - 当用户展开组件时，系统应把内部功能作为只读说明，不能显示为可安装复选项。
2. 作为首次安装用户，我希望快速选择合理方案。
   - 当用户选择推荐、最小或全部方案时，系统应立即更新组件选择和待应用更改。
3. 作为已安装用户，我希望明确知道本次操作。
   - 当目标未安装、版本可更新、组件变化或配置无变化时，主按钮应分别显示安装、更新、应用更改或已是最新配置。
4. 作为维护人员，我希望看到每个目标和组件的状态。
   - 当目标被选择时，系统应显示其可用状态、CDBox 版本和组件的已安装、待安装、待删除、可更新、必需或不兼容状态。
5. 作为普通用户，我不希望被技术细节干扰。
   - 当前置环境正常时，系统不得显示独立运行组件区。
   - 当前置环境异常时，系统应显示可自动修复的明确提示。
   - 安装日志默认应折叠，用户可按需展开。
6. 作为用户，我希望安装前能看到 CAD 是否可安全操作。
   - 当 AutoCAD 未运行时，系统应显示可安装状态。
   - 当 AutoCAD 正在运行时，系统应显示警告并禁用实际安装、更新、修复和卸载操作，重新检测后恢复。
7. 作为高级用户，我希望管理已有安装。
   - 已安装目标应提供修复安装、查看安装位置和卸载 CDBox 的次级菜单；卸载不得与主操作同级突出。

## 非目标

- 不把一个 DLL 内部的功能伪装成可独立安装组件。
- 不改变现有业务程序集边界和安装目录格式。
- 不引入 CloudBase、数据库或在线账户能力。
