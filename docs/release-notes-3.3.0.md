# CDBox Studio Preview 3.3.0 修改信息

发布日期：2026-07-30

发布通道：`studio-preview`

版本码：`30300`

## 图框、裁图与纵断面

- 新增自定义图框模板管理、图幅分类、单双列预览、留白、比例文字和指北针设置。
- 新增裁图区域布置、方向选择、图框批量布置与直接布框流程，并统一使用浮窗完成模板和方式选择。
- 改进模板图纸导入、插入定位、锁定图层裁剪、辅助框排除和物理裁剪，减少 XCLIP 下对象缺失或越界。
- 新增纵断面生成及设置界面，可按联通管线与井属性生成自然地面、设计管内底、埋深、井深、坡度、距离和井号等内容。
- 修复纵断面写入阶段的 `eNotApplicable`，生成失败时不向图纸保留不完整结果。

## Excel 转 CAD 与统一界面

- 新增 Excel 转 CAD 表格，支持分解线文字、CAD 原生 TABLE 和块三种形式。
- 支持读取所有已用单元格、Excel 中用户选择的连续区域和页面打印区域，并记忆表格设置。
- 改进合并单元格、行高列宽、单行文字、颜色、背景、图层和连续边框复刻。
- 颜色选择器、Excel 转 CAD、图框、纵断面和简码设置统一接入 WebView2 页面架构，同时保留所需独立窗口。
- Excel 转 CAD 已加入工作台，菜单入口、工作台入口和独立页面共用同一套业务逻辑。

## 标注、属性与图层

- 管长、节点及表面积标注共用浮窗样式、动画、透明度与位置记忆；完善重叠管线候选选择和高亮确认。
- 完善标注绑定、重新绑定、对象复制后的属性隔离，以及管线长度、开挖宽度等属性变化后的注记同步。
- 节点标注增加节点绑定与所见即所得定位，节点属性变化后可同步更新。
- 属性编辑器增加双击打开、重叠对象选择、批量编辑后的注记检查，并统一两位小数的四舍五入显示。
- 图层管理器增加多选、框选、Shift 选择、默认管线图层预设及自定义预设。
- 改进主管、支管、注记和井规格识别，完善特殊对象与数据质量检查规则。

## 工程量、更新与辅助工具

- 工程量看板改进首次打开时的读取与计算策略，减少误打开造成的 CAD 卡顿。
- 新增工程量计算过程导出，记录每条管线、每座井的计算明细，便于核对人工计算结果。
- 新增安全的简码识别及设置，可配置识别符、连接首尾相邻点和自动闭合。
- 更新检查使用 Gitee、GitCode、GitHub 三个内置源按优先级自动重试，并在启动时只提示可用更新。
- 恢复首次加载安装提示，优化菜单即时加载、菜单分组和更新器启动提示。
