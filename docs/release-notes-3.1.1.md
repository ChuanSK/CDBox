# CDBox Studio Preview 3.1.1 修改信息

发布日期：2026-07-20
发布通道：`studio-preview`
版本码：`30101`

## 界面与交互

- 统一精简图层管理器、属性识别表、标注设置、断面生成、属性默认表和属性编辑器的内嵌/独立界面，删除重复标题、恢复默认、关闭及旧版入口等冗余控件。
- 调整各窗口按钮布局、标题栏层级与圆角，使内嵌页和独立窗口保持一致。
- 新增 Studio 设置页与独立设置窗口，统一常用设置入口和消息提示样式。
- 断面生成完成后不再返回原界面；独立窗口生成后自动关闭。

## 工程量与属性编辑

- 精简属性编辑器对象信息，仅保留图层、类型和 CAD 长度，并将智能刷新统一为刷新。
- 完善主管、支管、节点/井和特殊对象的属性识别、默认值联动与结构层计算。
- 特殊对象不再被主管/支管智能规则覆盖；锁定、冻结或关闭图层上的对象会安全跳过并给出汇总提示。
- 提高数值持久化精度，完善批量写入、默认表补填、属性清除和工程量依赖刷新。

## 断面生成

- 新增断面比例换算服务，使文字、尺寸和图形按设置比例一致生成。
- 新增断面对象绑定服务，完善生成对象与来源数据之间的关联和刷新基础。
- 改进批量断面生成、设置持久化及独立窗口路由。

## 标注浮窗与管长标注

- 重构管长标注编辑浮窗：支持无系统边框拖动、调整大小、位置记忆和离开窗口后的透明度降低。
- 浮窗不再跟随注记或自动避让，重新打开时恢复上次关闭位置并限制在可见屏幕范围内。
- 将绑定点与引线点统一为一个高亮红圆；选中标注时显示，拖动空间编辑时暂停显示。
- 拖动引线点落到新对象后自动重新绑定；重新绑定按钮直接检测当前引线端点，无需再次选点。
- 绑定识别复用管长标注的直接点取规则：主管、支管按属性刷新标注内容，其他多段线使用“图层：长度”普通标注。
- 支持解绑、重新绑定、源对象属性/长度刷新和标注文字兼容迁移。
- 修复选择标注时由瞬态图形和选择回调重入引发的 AutoCAD 致命访问冲突。
- 修复调整注记位置时的闪烁、原注记残留、全图暂时消失及图形恢复问题。

## 稳定性与开发资料

- 更新 AutoCAD 启动、安装与更新器等待流程，统一依赖校验和用户提示。
- 补充标注浮窗、断面、属性编辑器和共享页面的核心回归验证。
- 将设计规范和实现说明集中整理到 `开发文档` 目录，便于后续电脑直接接续开发。
