# CDBox 5.1.7

本轮完善不动产“添加房屋”的层次管理、圆弧面积、底层占地汇总和房产文档导出。产品版本 5.1.7，数字版本码 50107。详细操作见 [房屋层次与房产文档](building-area-5.1.7.md)。

## 变化

- 点选与框选均可使用；每次选取作为一条层次，可新建幢或追加至已有幢。允许同名层次和特殊层次名，跨层计入倍数单独填写。
- 不规则直线边界优先共顶点划分，无共同可见顶点时完整回退；保持 n-2 个三角形，仅标注边长和计算必需的辅助长度。
- 支持闭合多段线圆弧段及圆，以解析弓形公式计算，保存半径、角度、π 与各项结果。
- 忽略未完全包含于正面积图形的中空，防止外部中空多扣减；凹边界及圆弧包含关系一并检查。
- 添加房屋和生成注记分开，分别提交与重试，不强制相互执行。
- 建筑面积按层次合计；每幢占地面积按其全部底层明细合计，宗地同步自动汇总。修改名称、层数、底层归属后，摘要、公式和合计即时更新。
- 接入用户“房产.docx”，默认导出“宗地名+房产.docx”。重复层次逐行呈现，包含每幢小计、占地和宗地合计；长表重复表头。
- 使用新版地籍调查表，房屋状况每幢一行，每页三幢，超过三幢续页。长层次移至完整说明，调查员和日期左右分列。修正模板空白行引起的封面、签章及房屋签署栏分页。
- 层次迁移兼容旧测量记录；旧编辑草稿与新选取结果按修订号合并，保护刚追加的层次数据。
