# 公共业务工作台重构

日期：2026-09-08。版本仍为用户指定的 5.1.1，本轮安装器使用独立产物目录。

## 完成范围

- 删除 CDBox 设置外观页中的“宗地调查 · 工作台预览”、待处理数量、示例房屋面积和自动保存示例提示，以及对应专用样式。保留内容字体、主题预设和自动保存功能。
- 公共业务入口改为三条工具入口：简码识别设置、图框设置、Excel 转 CAD。通过原有服务打开工具，保留旧入口签名以兼容反射调用。
- 简码识别设置采用简洁的符号设置和三项单行开关；支持键盘操作和可访问状态。
- 图框设置采用左侧模板库、右侧编辑区。保留图幅筛选、单/双列模板、几何预览、默认/删除、留白、指北针、比例和布框动作。设置块可折叠；关闭绘制项时隐藏其详细参数，重新打开保留原值。模板可通过键盘选择。
- Excel 转 CAD 按来源/范围与输出/参数划分两列，窄窗口转为单列。设置块可折叠，生成操作固定在底部；保留工作簿选择、实时区域读取、保存版本回退、图层、颜色和输出类型。
- 图框选择和提示对话框同步主题基础配色与 UI 字体。

## 主题与代码归属

上述 Web 页面均使用 `CommonWorkbench` 接入公共工作台颜色、字体和动画设置；已打开页面接受主题更新，不重新加载业务数据。深色模式的页面滚动条同步为深色。页面仅使用组间分隔，移除旧渐变、大阴影和卡片套卡片。

所有界面仍位于基础组件 `CDBox.dll`。`CDBox.Common` 只增加入口动作绑定，不承载页面或主题资源。污水及其他未选定界面不在本轮结构重构范围内。模块本身的版本保持 0.5.0。
