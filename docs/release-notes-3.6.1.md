# CDBox Studio Preview 3.6.1

发布日期：2026-08-12

本版本为预发行版本，主要更新如下：

- 完成悬浮球阶段性架构，统一承载通知、提示、进度、图纸检查和同步任务，并支持问题忽略、恢复及历史查看。
- 优化纵断面生成、设置和落图前预览，完善侧面接入、起终点外主管、网格、文字精度与图层样式；侧面接入口高程统一采用接口井的设计管内底标高。
- 新增污水管成果表范围选择、落图前预览与专用图层，完善井编号自然排序、坐标及井底标高输出。
- 优化图框模板、裁图区域和连续直接布框流程；修复旋转裁图矩形尺寸误判，并让被裁原块以裁后嵌套块保留，便于后续炸开编辑。
- 完善属性与标注同步、面积标注模式、通知迁移、更新器备份清理及多项稳定性处理。

安装包适用于 AutoCAD 2023 / CASS11，发布渠道为 `studio-preview`。
