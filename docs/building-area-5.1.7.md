# CDBox 5.1.7：房屋层次与房产文档

## 使用流程

1. 从不动产业务或宗地调查编辑器进入“添加房屋”，逐个点选或框选闭合多段线、圆，按 Enter 完成。一次选择对应一条层次明细。
2. 选择所属宗地和所属幢。可新建房屋，也可给已有幢追加层次；幢号、户号等仍允许留空。
3. 输入层次名称，例如“一层”“二至三层通道”。同名层次会分别保存。“计入层数”默认 1；跨层区域若需计入两层，明确填写 2，不从名称或房屋总层数隐式推断倍数。
4. 底层（1 层）勾选“计入占地面积”。常见一层、首层、底层名称会自动识别，也可手动调整；计入底层占地的明细必须为单层。
5. “添加房屋”写入调查数据；“生成注记”独立生成边长与计算辅助线。两个操作分别提交、分别重试，互不强制执行。
6. 房屋调查的“层次与面积明细”中可修改名称、计入层数、底层归属或删除明细。房屋建筑面积、占地面积及宗地合计同步刷新并自动保存。
7. 顶部“导出”菜单选择“导出房产文档”，默认名称为“宗地名+房产.docx”。原 Word、Excel、检查表出口保留，子选项使用普通菜单样式。

## 计算与注记

- 非“中空”“半封”图层计全面积；完全包含于一个房屋或半封闭合图形中的“中空”扣减；“半封”计一半。
- 外部或部分越出正面积边界的中空会忽略并提示。包含判断同时支持直线、圆弧和凹边界，不只检查中空顶点。
- 不对多个正面积图形做并集或重叠去重，不对越界中空进行裁剪。跨越多个相邻正面积图形的中空，需要先整理为可明确包含的闭合边界。
- 矩形沿用宽高公式；其他简单直线多边形优先寻找共同可见顶点，以最短总划分线生成 n-2 个三角形。无法共用顶点时回退完整耳切划分。每个三角形保留计算高度辅助线。
- 仅标注边界长度与计算实际用到的辅助长度；不再为未参与底高计算的划分线额外标长度。
- 支持水平平面内的二维闭合多段线圆弧段和圆。圆弧使用弦多边形面积加减弓形面积的解析公式，绘制半径辅助线，保留半径、角度、π 和分项公式；不会用弧线折线近似面积代替最终计算。
- 长度和半径保留两位小数，角度保留六位小数。每个图形先按公式汇总并保留两位小数，全面积、中空、半封加权后乘计入层数，最后保留两位小数，避免半封先舍入再乘层数造成分位误差。沿用图纸坐标单位。
- 当前接收闭合 LWPOLYLINE 和 CIRCLE，不自动拼接独立 LINE/ARC 对象。不支持倾斜平面、未闭合、自交或零面积边界；特殊圆弧导致弦多边形异常时会提示拆分。

## 汇总和导出

同一幢的建筑面积是全部层次明细计入面积之和；占地面积是该幢全部底层明细之和。同名底层分别计入，例如参考中的两个“一层”：127.62 + 27.14 = 154.76 ㎡。参考五条层次的建筑总面积为 486.55 ㎡。缺少底层数据时占地显示待汇总，避免将不完整结果当作总数。

房产文档沿用用户提供的“房产.docx”版式、字体、列宽及合并结构，每条层次独立占行，包含计算式、面积、每幢小计、占地和宗地合计。长表自动续页并重复表头。

调查表使用本轮提供的“地籍调查表.docx”：房屋状况每幢一行，每页三行，第四幢另起房屋调查页。较长的层次名称在窄列显示“见说明”，完整名称移到本页附加说明，房产文档中仍完整逐条呈现。多幢草图文字、调查说明及审核意见按幢汇集，调查员与日期分别保持在左右两侧。

旧测量记录会迁移为一条层次快照。面积仍是选取时的快照；修改 CAD 图形后需重新选取并替换对应层次。本轮未增加 CAD 修改监听、跨软件撤销联动或正面积图形重叠裁剪。

## 维护与验证入口

- 几何、模型、CAD、持久化和 Word 导出位于 `CDBox.RealEstate`；页面仍由基础组件提供。
- `BuildingAreaTableDataSource` 保留全部层次与计算快照，既有导出接口继续可用。
- `BuildingPropertyFeatureTests.cs`：三角划分、圆弧、包含关系、舍入、底层汇总、并发草稿和文档结构。
- `Export-BuildingPropertySamples.ps1`：通过正式业务程序集生成普通、圆弧、长表和四幢调查表样本。
- `Test-BuildingCaptureWorkbench.cjs`：添加与注记、同幢追加、重复层次、即时汇总、窄屏及原有编辑器回归。
