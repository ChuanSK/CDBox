# CDBox 5.1.8

本轮优化房屋几何计算，修正地籍调查表房屋行数和调查日期。产品版本 5.1.8，数字版本码 50108。操作与适用范围见 [使用说明](building-area-5.1.8.md)。

## 变化

- 直角边界优先矩形分割，比较两个方向的分块数量及辅助线长度，支持旋转后的 L、U、T 和阶梯形。
- 图示 U 形拆成三个矩形、两条水平分割线，复用外边尺寸推算高度，计算结果为 249.81㎡。没有增加三角形高度或重复的内部长度注记。
- 非直角边界仍可三角划分，圆弧保留解析计算，并可与矩形部分组合。
- 地籍调查表“房屋状况”按房屋记录数量增减：一幢一行、四幢四行；不再每三幢复制整张调查表。多幢自然续页，草图、说明与审核意见位于末尾。
- 房屋调查日期只替换模板年、月、日前的空白，保留单位、字体、段落格式和原横向起始位置。未填日期时保留年月日空位。
- 产品、安装器、安装清单和更新元数据同步到 5.1.8 / 50108。兼容的业务模块接口版本不递增。

## 验证

- 主程序与安装器构建：0 警告、0 错误。
- 核心检查：73 项通过，0 失败；涵盖矩形数量与覆盖范围、旋转、大坐标、三角形、圆弧、加权面积、保存和文档导出。
- UI 架构检查通过，8 种模块组合隔离检查通过。未修改页面交互流程。
- 实际业务程序集导出样本；四幢完整地籍调查表渲染为 7 页，房屋表在同一页显示四行。一幢、零幢与二十幢的房屋部分分别核验；二十幢连续显示在 2 页，无缺失或多余空行。
- 22 项文档结构与渲染回读检查通过。日期起始横坐标在模板、一幢、四幢、空日期、二十幢样本中均为 602.35 pt；全部页脚文字样式及段落属性保持一致。
- 新矩形计算式已进入房产文档，面积和占地结果均为 249.81㎡。
- 安装器自检成功；内嵌 42 个文件，五个程序集和四份模板与已验证构建逐项哈希匹配。

验证使用 LibreOffice 渲染。多页房屋表保留 Word 的重复表头属性，但当前 LibreOffice 对该合并表格未重复显示表头；数据行及日期完整。未在 Microsoft Word、真实 AutoCAD 窗口中执行人工验收，也未实际安装或上传云端。
