# CDBox Studio Preview 3.4.1

发布日期：2026-08-06

本版本为预发行版本，主要更新如下：

- 统一通知、提示与选择浮窗的视觉样式、动画、透明度和位置记忆，并精简标注过程中的冗余提示。
- 完善管长、节点、面积与表面积标注，增强属性变化后的绑定刷新、多行文字以及管径识别同步。
- 重构纵断面生成流程，支持起终点节点选取、连通路径识别、结构层基础读取，并按参考图完善图层、井轮廓、管线和数据精度样式。
- 优化图框裁图、锁定图层处理、模板导入、工程量看板响应，以及更新器对目标 AutoCAD 版本退出状态的识别。

安装包适用于 AutoCAD 2023 / CASS11，发布渠道为 `studio-preview`。
