# CDBox Studio Preview 3.6.2

3.6.2 是后续重要分支展开前的源码固定版本。本次仅更新 GitHub 源码基线与版本标签，不生成发布压缩包，不更新 `update.json`，也不创建 GitHub Release。

## 本版主要修改

- 悬浮球通知支持多条并列、优先级排序、滚动查看、忽略与恢复。
- 工程量统计区域可记忆，并统一约束同步和图纸检查范围。
- 主管属性增加起点、终点内底标高，并统一物理连接识别与纵断面取值。
- 纵断面补充侧面接入、连续主管、截断线、网格范围与块化输出优化。
- 图纸检查补充弱提示分类，并修正节点、管线连接及 CDBox 专用图层识别。
- 图框裁图、成果表图层和原块参照嵌套保留逻辑得到修正。
- 统一进度浮窗刷新机制，减少纵断面、批量任务及本地更新期间的 CAD 黑屏和假死。
