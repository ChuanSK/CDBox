# CDBox Studio Preview 3.2.0 修改信息

日期：2026-07-27

版本：`3.2.0`

版本码：`30200`

## 本版定位

3.2.0 是 3.1.1 之后累计开发成果的源码接续版本，用于在其他开发环境继续迭代。当前只推送源码，不创建 GitHub Release，也不发布安装包。

为避免现有用户收到无法下载的更新，仓库根目录及 `CDBox发布` 目录中的 `update.json` 暂时继续指向已经发布的 3.1.1。正式发布 3.2.0 安装包时，再同步更新文件名、大小、SHA-256、下载地址和发布说明。

## 主要修改

- 统一管长、节点和表面积标注浮窗的视觉外壳、透明度、光圈、拖动、吸附及开合动画。
- 完善管长标注绑定点显示、注记移动、引线点重新绑定、绑定内容刷新及选中状态恢复。
- 增加重叠长度对象选择浮窗，支持 Tab、方向键、滚轮、鼠标、回车和空格切换确认。
- 增加主管、支管、井等可编辑对象的双击属性编辑器入口，并修复窗口重复打开及关闭后的焦点恢复。
- 优化图层管理器多选、框选、Shift 选择、图层树及属性识别逻辑。
- 增加统一颜色选择器、ACI/TrueColor 处理和标准颜色配置。
- 完善属性编辑器、结构层、平均深度、小数位数、管径与外径同步及批量断面数据读取。
- 增加工程量计算过程导出，细化管线、节点及结构层计算明细。
- 更新器改为固定使用 Gitee、GitCode、GitHub 三个更新源并依次回退。
- 增加启动检查更新、首次加载安装提示、更新器等待 CAD 退出状态及本地更新持久提示。
- 菜单栏恢复为插件初始化时立即加载。
- 修复插件在保存过程中触发标注绑定刷新，导致图纸保存后再次显示未保存的问题。
- 将 `System.Security.Cryptography.Xml` 更新至 10.0.10，消除 10.0.9 的已知高严重性漏洞警告。

## 已知问题

- 双击完全或部分重叠的管线时，属性编辑器能够正常打开，但重叠对象选择浮窗仍可能不出现，通常直接打开 CAD 当前选中的上层管线。
- 该问题暂不在 3.2.0 中继续修改，详细排查入口和安全约束见 `开发文档/CDBox_3.2.0_Codex接续说明.md`。
