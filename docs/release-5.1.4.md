# CDBox 5.1.4

日期：2026-09-09。

## 本轮修复

- 地籍调查表 Word 导出：新建填写文字时复制空白段落中原有的字体、字号等格式，避免仿宋、宋体和小字号填写位置回退到文档默认格式。模板文件本身不变。
- 房屋基本信息调查表：调查员在左，日期使用与表格右缘对齐的制表位；逐幢续页同样生效。Excel 版原有左右独立单元格保留，并补齐调查员姓名。
- 安装时将完整安装器安装为 `%ProgramData%/CDBox/CDBox组件管理器.exe`。此步骤为安装前置条件，复制失败不再只留一条警告后报告安装成功；使用临时副本、内容校验和原子替换，已安装的相同副本可直接复用。
- 设置入口改为“打开组件管理器”，启动安装后的本地副本，继续支持增减业务模块和卸载。
- 内置用户提供的版本服务地址，移除地址输入框、保存参数及旧配置覆盖。保留 Stable/Preview 通道、版本查询及前往发布网站流程。
- 导出调查表主按钮保留强调色；下拉子选项恢复普通菜单样式，包括浅色、深色主题。
- 产品、安装器、清单版本为 5.1.4，数字版本码 50104；下一轮无特殊说明时使用 5.1.5。

## 验证

- Release514 优化构建通过，0 警告、0 错误。
- 核心测试 64 项全部通过，包含模板空白格式完整继承、多幢房屋左右签署栏、组件管理器首次复制/升级/同文件复用/失败保留旧副本、内置接口优先级。
- 宗地编辑器 422 项、设置页 134 项浏览器回归通过；另实测浅深主题导出菜单子项背景透明、不被标记为主要操作。
- Word 导出样本实际渲染为 11 页，检查了整体分页及宗地基本表、房屋表字体和左右签署栏。内置渲染脚本因缺少 LibreOffice 无法运行，改用本机 Word COM 打开独立只读测试文档导出 PDF，再用随附 Poppler 渲染图片进行检查；未修改用户文档。
- UI 架构检查与 8 种模块安装组合检查通过。
- 真实版本服务 Stable/Preview 只读 GET 均为 HTTP 200，响应通道正确，测试时最新版本均为 5.1.1。
- 最终安装器自检通过，41 个内嵌文件中的五个核心/业务程序集及三份模板与正式构建逐一匹配。
- 用最终安装器内的生产复制方法在隔离目录生成组件管理器；副本与原安装器逐字节一致，并独立通过 --verify-payload 自检。

浏览器使用真实程序集生成页面、示例数据和模拟 CAD 消息。未实际安装到 AutoCAD，也未在真实 CAD 设置窗口中启动组件管理器。未上传或发布安装包。
