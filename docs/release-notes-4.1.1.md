# CDBox Studio Preview 4.1.1

发布日期：2026-08-22

本版本为预发行版本，使用一个统一安装包，不再区分 AutoCAD 2016 与 AutoCAD 2023。

## 本版主要修改

- 新增不动产业务模式、独立菜单和宗地调查数据编辑器，宗地数据可绑定区域或权属线独立维护。
- 完善权属线识别、界址点自动编号、界址段与邻宗信息连续选择、界址签章分组及界址说明生成。
- 新增建筑物边长注记、复杂建筑面积辅助线及统一注记设置。
- 接入权籍调查表 Excel、地籍调查表 Word 与四张检查表导出，支持不完整宗地导出空白字段。
- 修正界址点坐标 X/Y 对应关系、界址点位说明优先级和不动产/污水管线菜单布局。
- 修复 AutoCAD 2016 跨图纸复制粘贴可能引发的卡死崩溃，并保持与 AutoCAD 2023 相同的发布程序集。

## 兼容与验证

- 统一安装包面向 AutoCAD 2016 与 AutoCAD 2023，不按宿主版本拆分。
- Release 配置构建通过。
- `CDBox.CoreTests` 全部通过。
