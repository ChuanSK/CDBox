# 添加房屋与面积计算（5.1.6）

## 使用流程

1. 在不动产业务选择 **添加房屋**（保留原命令 `CDREBL` 及既有别名），也可从宗地调查数据编辑器的房屋调查页进入。
2. 指定矩形框的两个角点，完整框入一间房屋的边界及其“中空”“半封”图形。
3. 页面显示全面积、中空扣减、半封全面积、最终建筑面积及可展开的计算明细。选择所属宗地，按需填写幢号、户号、所在层、总层数、结构；这些房屋属性允许留空。
4. 点击 **添加并注记**，写入所选宗地的房屋调查，并在 CAD 中生成边长、三角划分线、各三角形的高度辅助线及其长度。
5. 可以继续框选下一间或查看房屋调查。取消重新框选会恢复原页面，新一轮有效框选会替换上一轮的计算和提交回调。

## 面积规则

| 图层 | 计入规则 |
| --- | --- |
| 中空 | 扣减该图形全面积 |
| 半封 | 加上该图形全面积的一半 |
| 其他图层 | 加上该图形全面积 |

识别完整图层名，去除首尾空白和外参名前缀；不会把“房屋中空说明”识别成“中空”。计算按选中的图形求和，不进行重叠图形的并集、相交裁剪或自动层数乘算。每次应只框选一间房屋及其组成图形。

例如：`100.00 − 10.00 + 8.00 × 0.5 = 94.00 ㎡`。

矩形使用宽 × 高；其他简单多边形使用完整三角划分，含凹多边形、L 形和斜四边形。每个三角形采用最长边作底边，并将对顶点垂直投影到该边，绘制高度线。每项计算保存底边、顶点、垂足和三角形坐标。

长度注记和公式中的底、高统一保留两位小数，按四舍五入处理半分位；先累加各三角形底 × 高 ÷ 2，再将每个图形面积、最终建筑面积保留两位小数。几何原始面积用于检查三角划分是否完整，最终面积以注记公式为准。统一顶点方向和起点，避免同一边界反向或换起点后产生不同的分割和舍入结果。

沿用现有注记样式设置及 `CDBox-不动产-建筑边长注记` 图层。当前接收水平平面内、无圆弧段的闭合二维多段线；未闭合、自交、折返、零面积等无效边界会在提交前报错。沿用图纸坐标长度单位，不新增单位换算。

## 调查数据同步

- 框选得到的房屋建筑面积显示为“自动”，由保存的公式计算结果提供。
- 宗地建筑总面积改为房屋建筑面积的自动汇总；手工房屋缺少面积时显示待汇总，明确“不适用”的房屋面积不参与汇总。删除全部房屋后总面积为 0。
- 幢号、户号、层数等仍可在原房屋主从编辑器中补填。总层数不重复乘算建筑面积。
- **建筑占地面积、宗地建筑占地总面积保持现有填写方式，不由本次框选改写。**
- 计算明细随房屋保存，房屋详情可手动展开查看。既有房屋数据可以继续读取、修改和导出。
- 本次计算是框选时的快照。后续改变 CAD 边界，需要删除对应调查房屋后重新框选；本轮未增加 CAD 修改监听或 CAD 撤销与外部调查记录联动。

提交时复核当前图纸、绘图空间和源图形内容，避免使用过期计算。已被房屋记录引用的图形不能再次添加；重复点击同一提交也不会重复写入。写入调查文件后提交 CAD 事务，事务失败会恢复调查数据。编辑器旧草稿按房屋新增修订号合并，保护新添加房屋及其他正在填写的字段。

## 预留表格接口

`BuildingAreaTableDataSource.Create(record)` 返回每间测量房屋的数据：所属宗地、房屋标识、幢号、户号、图形来源、图层、计入系数、公式、底高长度、分项面积、最终结果和辅助线坐标。

`IBuildingAreaTableExporter.Export(BuildingAreaTableData data, string outputPath)` 为模板确定后的表格适配接口。本轮不虚构表格模板或新增尚未接通的导出按钮。

业务模型、算法、CAD 交互和持久化位于 `CDBox.RealEstate`；页面位于基础组件 `CDBox_Integrated/UI/Business/RealEstate`。共享页面契约新增可选的窗口替换标记，用于防止连续框选复用旧计算回调。污水业务算法不变。

## 验证入口

- `tests/CDBox.CoreTests/BuildingAreaFeatureTests.cs`：凹多边形、钝角三角形、斜四边形、大坐标、反向/换起点、底高垂直、面积闭合、舍入、中空/半封、持久化、旧草稿合并和失败回滚。
- `tests/Export-BuildingCapturePreview.ps1`：从实际编译程序集导出添加页面、宗地编辑器及计算样本。使用 Windows PowerShell 运行。
- `tests/Test-BuildingCaptureWorkbench.cjs`：实际页面的提交、重试、留空、主题、宽度、同步、删除、只读面积和既有编辑器交互回归。预览使用隔离的消息模拟，不会写入真实 CAD 或调查文件。
- `tests/Test-UiArchitecture.ps1` / `tests/Test-UiModuleIsolation.ps1`：UI 归属与模块组合隔离。

实际 CAD 鼠标框选、绘图注记、安装过程需在 AutoCAD 中验收；自动化页面预览不替代这部分现场验证。
