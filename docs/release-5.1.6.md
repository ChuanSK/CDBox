# CDBox 5.1.6

本轮将不动产“注记建筑边长”升级为“添加房屋”，接通 CAD 框选、面积计算、注记、所属宗地选择和房屋调查录入。使用方法及数据接口见 [添加房屋与面积计算](building-area-5.1.6.md)。

- 每次完整框选一间房屋：其他图层计全面积，“中空”扣减全面积，“半封”加上全面积的一半。
- 矩形使用宽高公式，其余简单多边形三角划分；每个三角形绘制高度辅助线并标注长度。公式使用与注记完全一致的两位小数底、高。
- 选择所属宗地后，幢号、户号、层数、建筑结构允许留空；确认后加入房屋调查，保留手工录入入口。
- 房屋建筑面积和宗地建筑总面积自动同步，建筑占地面积维持原填写方式；层数不重复乘算本次平面面积。
- 房屋保存图层、来源、三角形、底高、公式、计入系数和计算结果，提供未来表格模板的导出接口。
- 防止重复图形计入；提交时检查图纸、绘图空间和边界变化；旧编辑草稿会合并新添加的房屋；CAD 提交失败恢复调查文件。
- 添加页面采用基础组件的工作台主题，支持浅深色、预设与强调色；连续框选替换旧计算窗口，取消框选恢复原页。
- 产品、安装器及清单为 5.1.6，数字版本码 50106；下一轮默认使用 5.1.7。
