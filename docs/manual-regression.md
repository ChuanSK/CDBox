# CDBox AutoCAD 2023 / CASS11 人工回归清单

这份清单用于无法在普通单元测试中覆盖的 AutoCAD Database、Editor、WebView2 和 CASS 集成流程。测试图纸必须使用副本，更新器测试必须使用可恢复的测试安装。

> 2026-07-12 Preview 6 接手验证：Studio 显示、图层管理、标注和工程量看板已由用户在桌面 AutoCAD 中确认正常。详细记录见 `docs\host-validation-2026-07-12.md`。

## 1. 测试前准备

- [ ] 复制一份包含主管、支管、检查井、闭合边界和高程点的代表性 DWG。
- [ ] 记录 AutoCAD 版本、CASS 版本、WebView2 Runtime 版本和 Windows 版本。
- [ ] 关闭其他 AutoCAD 进程，避免更新器把它们识别为阻塞进程。
- [ ] 运行核心测试：

  ```powershell
  dotnet run --project tests\CDBox.CoreTests\CDBox.CoreTests.csproj -c Debug
  ```

- [ ] 构建解决方案并确认 0 错误：

  ```powershell
  dotnet build CDBox.sln -c Debug --no-restore
  ```

- [ ] 可选：设置 `CDBOX_HEADLESS_SELFTEST=1` 后用 AutoCAD Core Console 加载插件并执行 `CDSELFTEST`，确认输出 `CDBOX_SELFTEST_RESULT=PASS`。

## 2. 加载与启动

- [ ] 在 AutoCAD 执行 `NETLOAD`，选择 `bin\Debug\net48\CDBox.dll`。
- [ ] 命令行出现 CDBox 加载提示且没有未处理异常。
- [ ] 顶部“超重氢工具箱”菜单出现；`CDMENU` 可重建，`CDMENUDUMP` 可输出诊断。
- [ ] `CDCBL` 打开停靠侧栏，左右停靠、自动隐藏和关闭均正常。
- [ ] `CDBOX` 打开经典工具箱。
- [ ] `CDSTUDIO` 和 `CDS` 均能打开同一个 Studio 窗口，不重复创建实例。

## 3. Studio 外壳

- [ ] 明亮、蓝紫、深色三种主题可切换并在重新打开后保留。
- [ ] 收藏、取消收藏、最近使用和清空最近记录正常。
- [ ] 命令搜索可通过按钮和快捷键打开，筛选结果正确。
- [ ] 图层管理器、标注设置、属性默认表、属性识别表可在内嵌页和独立窗口打开。
- [ ] 独立窗口可拖动、缩放、最小化和关闭，边缘没有多余可见外框。
- [ ] 断开网络后执行“检查更新”，Studio 仍可操作并显示失败结果，不应冻结约 15 秒。

## 4. 图层管理器

- [ ] 创建若干测试图层并设置颜色、开关、冻结和锁定状态。
- [ ] 新版 WebView2 页面与旧版 WinForms 页面显示的图层数量一致。
- [ ] 批量开关、冻结、锁定、只显示所选和全部显示结果正确。
- [ ] 图层父属性、分类和标签保存后，关闭并重新打开图纸仍存在。
- [ ] 属性识别规则按“精确、包含、通配符、正则”分别测试至少一条。
- [ ] 自动识别不会覆盖用户数据，除非明确选择覆盖。

## 5. 标注模块

### 表面积标注

- [ ] 使用闭合边界和有效高程点执行 `BMJ`。
- [ ] CASS `surfacearea` 被正确调用，结束后自动进入注记定位。
- [ ] 结果与 CASS 原始结果一致；临时三角网按设置清理。
- [ ] 中途 ESC、无高程点、无效边界时能安全退出并给出可理解提示。

### 管线长度标注

- [ ] `GCBZ` 能在不同缩放级别正确点取 2D/3D 多段线。
- [ ] 实际长度与手动统计长度的优先级正确。
- [ ] 图层联动、文字样式、颜色、上下文字和来源 Xrecord 正确。
- [ ] ESC 退出后不残留预览或数据库对象。

### 节点标注

- [ ] `JDBZ` 能从工程量属性、图层元数据和邻近文字识别节点。
- [ ] 检查井、沉泥井和 315 井分类正确。
- [ ] 光标预览吸附正确；落图后只生成配置要求的对象。

## 6. 断面与图框

- [ ] `DM` 打开 Preview 10 独立窗口；Studio“断面”分类可打开同一共享页面的内嵌版本。
- [ ] SVG 预览中的结构层、填充、管道圆、管径文字、标题和尺寸线随参数实时更新。
- [ ] 预览支持滚轮缩放、拖动平移、放大、缩小和适应窗口。
- [ ] 结构层和层内管道均可直接编辑并拖动排序，保存后重新打开仍保持一致。
- [ ] “在图中生成”可进入 CAD 点位选择并按 1:1 正确放置断面图。
- [ ] `DMLEGACY` 仍可打开旧版 WinForms 界面。
- [ ] `PLDM` 能从已写入属性批量生成断面并正确排序节点编号。
- [ ] `TCFRAMEADD` 可从现有块和外部 DWG 创建模板。
- [ ] `TCFRAMECUT` 按方向和搭接长度布置图框、裁图范围和指北针。
- [ ] 图框流程不切断或修改原始业务实体。

## 7. 工程量属性与正式报表

- [ ] 单选对象执行 `SX` 打开 Preview 9 独立 WebView2 属性编辑器；`SXLEGACY` 仍可打开旧版窗口。
- [ ] Studio 的“属性编辑器”卡片打开内嵌页，内嵌页和独立页字段、智能刷新、默认表重填和保存结果一致。
- [ ] 主管支持选择起点井、选择终点井、调换起终点；保存后起终点深度与平均深度正确。
- [ ] 支管与节点/检查井只显示各自字段，切换对象不会遗留上一类型的界面或值。
- [ ] 保存后关闭并重开编辑器，全部可见字段、结构层和备注可回读，工程量看板收到数据变更刷新事件。
- [ ] 分别选择主管、支管、检查井执行 `SX`，类型自动识别正确。
- [ ] 默认表只带入模板字段，不带入节点编号、起终点、手动长度和备注。
- [ ] 属性写入后保存、关闭、重新打开 DWG，数据仍可读取。
- [ ] `SXQC` 只清除所选对象的 CDBox 工程量属性。
- [ ] `GCL` 同时统计启用的主管、支管和井类。
- [ ] Excel 模板存在，导出文件可由 Excel 打开，公式、单位和合计正确。

## 8. 工程量动态看板

- [ ] Studio 内嵌看板顶部“独立窗口”、命令面板“工程量动态看板 · 独立窗口”和 `CDQBOARD` 均复用同一独立窗口实例。
- [ ] 内嵌看板与独立看板同时打开时，切换图纸、实时统计、手动刷新和进度提示能同步到两个页面。
- [ ] 独立看板继承 Studio 主题与动画设置，窗口可拖动、缩放、最小化和关闭。
- [ ] 整张图纸统计与正式 `GCL` 的主管、支管和井类基础数据一致。
- [ ] 新建矩形区域、绑定已有闭合多段线、重命名、定位、修改和删除均正常。
- [ ] 区域统计只读取区域内工程量对象；大图纸下耗时明显低于整图统计。
- [ ] 管线相交按整条计入，点状对象按中心点计入，与页面说明一致。
- [ ] 315 井、化粪池等其他设施分类符合图层规则。
- [ ] 数据完整度、问题计数和失败对象列表正确。
- [ ] 看板选择对象、缩放对象和打开属性编辑器能联动回 AutoCAD。
- [ ] 开启实时模式后，新增、修改、删除对象并结束命令，看板触发刷新。
- [ ] 关闭实时模式后不自动刷新；手动刷新仍可用。
- [ ] 保存快照、复制摘要和导出参考表均成功。
- [ ] 统计失败时可显示上次缓存，并在 `%APPDATA%\CDBox\Studio\studio.log` 记录错误。

## 9. 安装与更新器

- [ ] `CDUPDATE` 选择仅包含 `CDBox.dll` 的目录时必须拒绝更新，并列出 WebView2、Loader、Updater 等缺失文件。
- [ ] `CDUPDATE` 选择 `bin\Release\net48\CDBox.dll` 时，暂存自检通过后才安排替换；关闭 AutoCAD 后完整依赖随主 DLL 一起更新。
- [ ] 模拟延迟复制失败时，旧 `CDBox.bundle` 从 `.update-backup` 自动恢复，不留下只有主 DLL 的半安装状态。
- [ ] 在测试环境执行 `CDINSTALL`，确认生成完整 `CDBox.bundle` 且下次启动自动加载。
- [ ] 使用 `scripts\New-CDBoxRelease.ps1` 生成测试包，清单大小和 SHA256 与 ZIP 一致。
- [ ] 用错误 SHA256 测试，下载或安装必须中止。
- [ ] 启动更新后保持 AutoCAD 打开，确认更新器只等待、不替换 bundle。
- [ ] 正常关闭所有 AutoCAD 进程后，更新器完成替换并保留旧 bundle 备份。
- [ ] 检查 `%APPDATA%\CDBox\Studio\updater.log` 和 `last-update-result.json`。
- [ ] 使用缺少必要文件的测试包，确认安装失败且旧 bundle 自动回滚。
- [ ] `CDUNINSTALL` 清理自动加载注册；DLL 被占用时能在 AutoCAD 退出后延迟删除。
