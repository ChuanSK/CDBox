# 宗地调查数据编辑器：工作台外观试点

日期：2026-09-07。

该编辑器已纳入 5.1.1 正式安装器，新主题系统与交付信息见 [设置工作台与主题系统](settings-workbench-5.1.1.md)。下文保留前三轮编辑器试点设计与验证记录。

本次只接入 `realestate-parcel-survey-editor`。所有实现仍编译进基础组件 `CDBox.dll`，不动产业务模块不新增 UI、主题或页面依赖。

## 结构与交互

- 左侧一级导航增至 184 px，六个业务页签名称与右对齐的强调色待处理数量分开排列。导航栏上缘直接连接原生标题栏下缘，贯穿页面全高；宗地工具栏与工作区左边缘对齐。选择列表省略“当前宗地”文字，保留无障碍名称。
- 普通字段固定为两列，长文本沿用跨两列显示。字段之间不再画分割线，仅在分组之间分隔；表格继续保留行分隔线。
- 使用中性主按钮和选中态，字段来源保留低饱和度语义色与文字。
- 侧栏收起时，左侧 12 px 边缘或标题栏切换按钮悬停可临时展开。离开后延迟 200 ms 收回，展开/收回使用 240 ms 缓动。悬停只移动覆盖层，不改变工作区位置和宽度。
- 自动收起阈值由最小录入宽度 776 px 加侧栏宽度 184 px 得到，即 WebView 可用宽度 960 px；增宽只恢复原本显示的侧栏，原本手动隐藏的仍隐藏。原生窗口外框不计入这个宽度。
- 界址表按实际工作区的容器宽度隐藏次要列，控件及数据保留在 DOM 内，收起、展开和保存均不清除列值。支持尺寸下避免横向滚动。
- “存在代理人”“沿用宗地权利人”占一整行，勾选项、标签和来源在同一行；关联字段或沿用信息从下一行开始排列。
- 界址点列表的闭合勾选和新增按钮，以及界址段、签章分组、界址说明的功能按钮均与块标题同行。“重新生成说明与四至”改名为“刷新界址说明”。
- 补充字段标签关联、数据来源选择器名称、导航当前页标记和键盘焦点样式。
- 三点按钮支持悬停或点击，向右展开重命名与删除；离开未固定的菜单后收起，Escape 和外部点击关闭，隐藏操作不进入键盘焦点。
- 保存按钮替换为自动保存状态与失败时的“重试”；沿用业务数据结构和导出提示。

### 列隐藏顺序

断点基于 `.workspace` 的实际宽度，而非整个窗口宽度，侧栏恢复或临时覆盖时无需另外计算表格尺寸。

| 表格 | 隐藏顺序及工作区断点 |
| --- | --- |
| 界址点列表 | X/Y 坐标：900 px |
| 界址段列表 | 相邻权利人：1100 px；中间点号：980 px；方向：880 px；距离：800 px |
| 界址签章分组 | 指界日期：1040 px；本宗指界人：920 px；邻宗指界人：800 px |

### 待处理数量与折叠

待处理数量统计当前条件下适用的必填字段缺值、无效选项或“待确认/未确认”，并包含界址表中的关键缺项；不启用的代理人字段、不适用项不计入。纸面签章保留空白的日期和签名人员不强制计数。房屋页合并各幢房屋的待处理项。数量随录入和条件变化更新，不作为阻止导出的条件，也不代替完整业务校验。

普通分组及界址表格可用标题左侧箭头折叠；房屋使用下述主从结构和分类编辑，不再逐幢展开全部属性。适用必填项填写完成，或整组均为有值的自动/默认项时自动折叠；无值的自动必填项仍保持展开。完成分组初次打开时折叠。正在输入的分组等待焦点离开后再折叠；手动展开的完成分组不会立即再次收起。手动折叠/展开按宗地保存，并在切页后保留。

自动/默认字段先呈现文本，点击后进入编辑；只打开编辑器不修改时保留来源，实际修改后转为人工。Escape 恢复本次编辑前的值与来源。隐藏输入控件和折叠分组仍参加原有数据同步，长文本原有高度继续保留。带中文方向的房屋墙体字段使用独立 ID，避免多个标签指向同一控件。

## 房屋主从结构

房屋页优先显示房屋调查工作区：左侧为可滚动的房屋列表（编号、两位小数面积、待处理数量及新增入口），右侧为当前房屋。初次选中及切换房屋后只显示幢号、户号、总层数、所在层、结构、建筑面积摘要。

点击“编辑详情”进入基本信息、面积、权属、其他四个分类；现有逐幢模型没有独立用途字段，不虚设用途分类。一次只挂载当前房屋当前分类的输入控件，切换前同步回完整草稿，保存仍包含所有房屋所有字段。新增房屋会自动选中并进入基本信息编辑，删除后选择相邻房屋。列表编号、面积和待处理数量即时更新，分类页签支持方向键、Home/End。所选房屋和分类按宗地记忆。项目参考信息、房屋权利人等共用分组位于主从工作区下方。

实现位于基础组件的 `ParcelSurveyEditorBuildings.cs`，样式仍统一在 `ParcelSurveyEditorStyles.cs`。

## 自动保存

`ParcelSurveyEditorAutoSave.cs` 在输入停止 600 ms 后合并保存，离开输入区或窗口失焦时立即提交。一次只有一个未确认请求；保存期间继续修改，会在上次确认后补存最新完整草稿。只有宿主确认落盘后才显示“已自动保存”，正常保存不刷新页面、不弹成功通知。保存失败或 10 秒未确认时保留页面草稿并提供重试。

新增 `autoSaveParcel` 路由返回请求序号对应的成功/失败回执，使用 `SavePreservingCurrentScope`，不改变当前宗地，也不插入已被删除的记录。切换宗地、重命名及删除操作等待最后草稿保存成功，随后暂停旧页后台保存；操作失败可恢复原页面。

`CDBoxStudioWebPageForm` 仅对该编辑器的用户关闭动作等待最终保存回执，再关闭窗口；保存失败不关闭。该保护是普通关闭链路，不承诺操作系统强制终止或 CAD 崩溃时的最后瞬间数据。CAD 宿主新版仍需实际加载验收。

## 主题来源及范围

从本机 Codex 26.901.6511.0 的 `webview/assets/app-initial-5b0a474bff5e.css` 核对默认 electron-light/electron-dark 定义：

| 色彩角色 | 浅色 | 深色 |
| --- | --- | --- |
| 内容面 | `#ffffff` | `#181818` |
| 侧栏/标题栏 | `#f9f9f9` | `#000000` |
| 主要文字 | `#1a1c1f` | `#dfdfdf` |

`CDBoxWorkbenchAppearance` 集中管理这些基础色、交互色、分割线和语义状态色。`ParcelSurveyEditorStyles` 管理试点布局和表单控件；`ParcelSurveyEditorInteractions` 管理待处理统计、行内编辑与折叠状态。

当前试点复用已有 CDBox 外观设置：`dark` 使用新深色；`light` 使用新浅色；旧 `fresh` 在此编辑器中映射为中性浅色，持久设置不变，其他页面仍按原主题显示。本次没有扩展全局设置选项、添加 Codex 全套预设或自定义主题编辑器。

页面每次生成读取外观设置，原生宿主同步标题、窗口按钮、背景及边缘颜色。修改设置后重新打开/刷新编辑器应用。预览中的浅色/深色按钮只改变示例页面，不保存全局设置。

## 复现

```powershell
dotnet build tests/CDBox.CoreTests/CDBox.CoreTests.csproj -c Release --no-restore -m:1 -p:BuildInParallel=false "-p:OutDir=$PWD/artifacts/parcel-workbench/build/"
& ./artifacts/parcel-workbench/build/CDBox.CoreTests.exe
./tests/Test-UiArchitecture.ps1
./tests/Test-UiModuleIsolation.ps1 -BuildDirectory "$PWD/artifacts/parcel-workbench/build"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Export-ParcelWorkbenchPreview.ps1
python -m http.server 8765 --bind 127.0.0.1 --directory artifacts/parcel-workbench/preview
```

打开 `http://127.0.0.1:8765/`，点击“运行交互检查”。预览的尺寸选择可用于人工核对布局。
