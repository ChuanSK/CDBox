# CDBox 5.1.9

重构图层管理器、属性识别表和建筑边长注记设置。产品版本为 5.1.9，数字版本码为 50109；兼容的业务模块接口版本保持原值。

## 界面调整

- **图层管理器**：改用平面分区、左侧分类导航和紧凑列表，移除工具栏、导航、列表、批量编辑区域的卡片阴影。保留行内编辑、Shift 多选、框选、批量操作、拖拽排序和图层预设。
- 窄窗口依次收起对象数、线型、打印、颜色、标签等次要列。点击状态打开图层详情，可查看完整信息、编辑标签及调用颜色选择器。列表仍使用 58px 虚拟行；窗口或工具栏高度变化后重新计算可见行。
- **属性识别表**：改为左侧规则列表、右侧选中规则编辑。匹配条件、输出属性和执行方式分组显示，搜索常驻；新增规则会清除筛选并聚焦名称。保留规则拖拽排序，并增加上移、下移及 Ctrl+S 快捷保存。切换规则保留草稿，待保存状态明确显示。
- 保留规则保存的 15 列编码契约以及原有匹配逻辑；原先未显示的对象类型、来源和置信度字段仍随数据保留。快速测试结果修正为真实换行。
- **建筑边长注记设置**：移除渐变卡片，按“注记文字 / 面积计算辅助线”分块，以标签和控件两列对齐。自适应开关、文字样式、高度、颜色、辅助线线型和线宽保持原有功能。保存按钮位于顶部，并显示未保存 / 已保存状态；颜色选择期间保留当前草稿。
- 三页接入同一工作台主题系统，支持浅色、深色、主题预设、自定义强调色和实时主题变更。遵循减少动画设置，主要动作使用强调色。

## 实现范围

界面资源作为基础组件的内嵌资源发布，通过 `UtilityWorkbench` 复用现有主题；不增加松散 Web 文件安装依赖。CAD 业务、房屋计算、文档导出及业务模块接口未作变更。

页面代码位于：

- `CDBox_Integrated/UI/Studio/LayerManagerPage.cs`
- `CDBox_Integrated/UI/Studio/LayerRecognitionRulesPage.cs`
- `CDBox_Integrated/UI/Business/RealEstate/BuildingLengthAnnotationSettingsPage.cs`
- `CDBox_Integrated/UI/WorkbenchAssets/`
