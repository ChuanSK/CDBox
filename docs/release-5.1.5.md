# CDBox 5.1.5

本轮完成污水管线业务界面重构。具体页面与实现边界见 [污水工作台说明](wastewater-workbench-5.1.5.md)。

- 工程量看板、对象属性、属性默认表、标注设置、横断面生成、纵断面设置统一到工作台外观。
- 扁平布局、分组分割线、双列录入、左侧分类和手动折叠；保存、导出、绘制等主操作使用强调色。
- 支持设置中的浅深色、主题预设、自定义配色与字体，主题即时切换保留页面草稿。
- 污水原生参数窗和标注浮窗同步主题；CAD 预览和图层颜色保留原有语义。
- 主界面侧栏与功能卡片统一打开新版污水窗口，纵断面内嵌页复用新版文档。
- 修正工程量指标组成展开不可见，以及“检查井”分类被误判为强调色操作的问题。
- 产品、安装器及清单为 5.1.5，数字版本码 50105；业务模块接口版本不变。下一轮默认使用 5.1.6。
