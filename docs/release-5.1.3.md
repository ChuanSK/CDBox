# CDBox 5.1.3

日期：2026-09-09。

## 本轮变更

- 宗地调查数据编辑器取消完成后自动折叠。无手动偏好时分组保持展开，完成状态、失焦及切换页签不再触发折叠。手动展开/折叠及已有手动偏好继续有效。侧边栏的窄窗口隐藏和悬停展开机制保持原逻辑。
- 工作台主按钮由前景色改为主题强调色，支持自定义、主题预设及强调色跟随前景。按钮文字按相对亮度选择黑色或白色，覆盖亮黄、黑白等极端配色。
- 所有 WebView 页面通过公共宿主接入强调色，包括尚未进行布局重构的页面。保存、导出、生成、应用等操作，以及选中导航、开关、焦点和待处理数量使用统一强调色；动态生成的操作按钮同样接入。
- 插件自有 WinForms 主操作按钮和 WPF 提示、边界输入、浮窗等装饰强调色接入同一配置。共享 WPF 强调色画刷接受设置更新。删除、错误、成功等语义颜色保留；CAD 实体颜色和颜色选择器中的业务色样不转换。
- 修正工作台窗口初次加载时，对单引号深色 HTML 的原生标题栏颜色判断。
- 产品、安装器、安装清单、更新元数据版本统一为 5.1.3，数字版本码 50103。后续未指定版本时按补丁号递增的约定写入根目录 `AGENTS.md`；同一轮重复构建不重复加版本。

- `Release513` 优化构建通过，0 警告、0 错误。

- 宗地编辑器浏览器检查 422 项通过，包括默认分组展开、完成后保持展开、手动折叠、两列布局、边界表格和自动保存。
- 设置页浏览器回归 133 项通过，覆盖五组主题预设、浅深切换、字体、导入复制、自动保存和失败重试。
- 跨页面强调色检查 228 项通过：图框、Excel、设置、宗地、建筑物边长、工程量、断面页面，浅深两种模式及蓝色、玫红、亮黄、白色、黑色强调色。动态加载的断面操作按钮也包含在内。
- UI 归属检查通过；8 种业务模块安装组合检查通过。
- 安装器自检通过；41 个内嵌文件中的五个程序程序集和三份宗地模板与本轮正式构建逐一匹配，安装器与包清单版本一致。

浏览器测试使用真实程序集生成页面、示例数据和模拟 CAD 消息，不写入用户设置或业务数据。原生 CAD 取点、绘图、Excel/WPS 连接和安装后窗口交互未执行。颜色选择器的 CAD 色板读取依赖真实宿主，不能用外部 PowerShell 进程验证；本轮对其使用统一宿主强调色接入，不改色板生成代码。没有上传或发布安装包。
